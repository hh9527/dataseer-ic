# 考官工具

考官方法与题目分开存放：

- `exam/考官须知.md`：考官的工作方法（职责、流程、澄清应答规则、记录表）。
- `exam/开场白.md`：定稿开场白，一字不改。
- `exam/questions/T<nnnn>.md`：一题一份，除题面外还带可澄清点、考核要点与追问。

题目文件以段分节，文件名就是题号；开头是 frontmatter，只有 `## ` 分节会发给考生：

```yaml
---
title: 告警级别构成
type: 问数        # 问数 | 报表 | 渐进
difficulty: 1     # 1–5
steps: 0          # 追问步数，与「## 追问 m」段数一致
---
```

```text
## 任务        题面；ask 发送时自动加「任务 T1016：」前缀
## 进入        递进题的定稿开场句（只有 T1016–T1018 有）
## 可澄清点    澄清应答口径（只给考官看，不能发给考生）
## 考核要点    （只给考官看，不能发给考生）
## 追问 m      追件正文；已含定稿话术，原样发出
```

列出题目：`just list`（`--json` 给脚本用）；frontmatter 的 `steps` 与追问段数不一致时会报警。

命令都在伞目录下用 `just` 执行，需要 Node.js 22 或以上版本，无第三方依赖。服务由宿主启动，工具只发请求，不启动、重启服务，也不清理考生文件。

## 发问

```sh
just ask 10924 --opening                        # 定稿开场白，一字不改
just ask 10924 --question T1001.md              # 发题面，自动加「任务 T1001：」
just ask 10924 --question T1016.md              # 递进题：题面 + 定稿「进入」句
just ask 10924 --question T1016.md --step 2     # 第 2 步追问，原样发出
just ask 10924 "随便说一句"                      # 自由文本
just ask 10924 --question T1001.md --dry-run    # 只打印将要发出的内容
```

`--question` 只写文件名时到 `exam/questions/` 下找，也可以给完整路径。`--step m` 取「## 追问 m」段；追问正文里已经带着定稿话术（「接着刚才那份稿继续看：」「好了，我们现在汇总这些信息完成最终的报告：」），所以**不再加「任务 T<nnnn>：」前缀**，免得把定稿措辞改坏。

`ask` 会一直等到本轮有结果：考生交活、或者发起澄清。默认等 180 秒，可用 `--timeout` 调整。

## 澄清与继续等

```sh
just submit 10924 --select "选项"     # 按选项澄清；没给选项时用原文
just submit 10924 "我自己写一句"
just wait 10924 [--timeout 180]       # 上一轮还没结束，继续等
```

状态机：`none → idle → running → pending → running → idle`。

- 只有 `idle` 能 `ask`，只有 `pending` 能 `submit`，越界会立刻报错而不是干等。
- `new-session` 会放弃旧会话、清空挂起提问与轮次状态，旧会话的事件一律无视。

## 会话

```sh
just new-session 10924               # 新建会话（清空挂起状态）
just new-session 10924 --clear       # 连带清掉考生工作区里的 *.dari
curl -s http://127.0.0.1:<考官端口>/state   # 看 sessionId / phase / pending
```

考官服务由 `just run-tester 10924` 拉起，端口写在 `.deploy/10924/tester/exam.port`，`touch .deploy/10924/tester/.ctrl` 可重启。
