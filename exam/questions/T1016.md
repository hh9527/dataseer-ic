# T1016　设备资源：从总体到单机

最近 3 天，各设备分类的 CPU 与内存平均使用率分别如何？

## 追问 1

依据分类结果，选出 CPU 平均使用率最高的分类（若并列，按分类名称升序取首个并说明规则）。

## 追问 2

对该分类：给出这三天每天的平均使用率趋势，以及该分类下 CPU 平均使用率前十设备清单。

## 追问 3

对该分类前十设备：给出窗口内 CPU 采样峰值与平均值的对照表，并指出按峰值排序与按均值排序的差异（至少说出榜首设备是否相同）。

## 追问 4

收尾：说「好了，我们现在汇总这些信息完成最终的报告：」，然后要一份「分类 → 分类内趋势 → 单机峰值」三级递进的报告（不超过 6 张图），正文说明每一步的取数范围与结论边界。
